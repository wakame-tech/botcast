## 機能概要

Canvas エクスポート機能の単体テストとして、`build_json_canvas` と `build_markdown` のロジックを検証する。DB 接続不要な純粋関数のテスト。

## 意図

エクスポート変換ロジックが仕様通りの出力形式を生成することを単体テストで保証する。

## シナリオ

### build_json_canvas が空の入力で空の Canvas を返す

1. 空のレコード・エッジ配列を渡す
2. ノード 0 件、エッジ 0 件の JsonCanvasResponse が返る

### build_json_canvas がレコードとエッジを正しく変換する

1. 2 件のレコードと 1 件のエッジを渡す
2. ノード 2 件（各レコードの data が text に含まれる）、エッジ 1 件が返る
3. ノードの type は `"text"`、x/y/width/height が設定されている

### build_markdown が空の入力でヘッダのみ返す

1. 空のレコード・エッジ配列を渡す
2. `"# Subgraph Export\n\n"` のみの文字列が返る

### build_markdown がレコードとエッジを含む Markdown を返す

1. 2 件のレコードと 1 件のエッジを渡す
2. 各レコードが `## {id}` セクションと JSON コードブロックで出力される
3. エッジが `## Relationships` テーブルの行として出力される
