## 機能概要

レコード間にラベル付きの有向エッジ（リレーション）を作成・一覧取得・削除できる。SurrealDB のグラフエッジ（`RELATE` 文）を活用し、任意のコレクションのレコード同士を関連づける。

## 意図

構造化データ同士の関係性（例：登場人物 → 所属組織、エピソード → 登場人物）を明示的にグラフとして管理することで、LLM エージェントが文脈を辿りながら情報を収集できるようにする。

## 主要なメンバー

- `Edge` — エッジモデル（`id`, `in`, `out`, `label`, `created_at`）
- `CollectionRepository::create_edge()` — SurrealDB `RELATE` でエッジ作成
- `CollectionRepository::list_edges()` — 指定レコードの関連エッジ一覧取得
- `CollectionRepository::delete_edge()` — エッジ削除

## シナリオ

### エッジを作成する

1. クライアントが `POST /canvas/edges` に `{ "from": "{table}:{id}", "to": "{table}:{id}", "label": "belongs_to" }` を送信する
2. API が SurrealDB に `RELATE from_record->edge_label->to_record` クエリを発行する
3. 201 Created で作成されたエッジ情報を返す

### レコードのエッジ一覧を取得する

1. クライアントが `GET /canvas/edges?record_id={table}:{id}` を送信する
2. SurrealDB から指定レコードの送信・受信エッジを取得する
3. 200 OK でエッジ配列を返す

### エッジを削除する

1. クライアントが `DELETE /canvas/edges/{edgeId}` を送信する
2. SurrealDB から該当エッジを削除する
3. 204 No Content を返す

### 存在しないレコードを指定してエッジを作成しようとする

1. クライアントが存在しないレコード ID でエッジ作成を試みる
2. API がレコードの存在を確認し、404 Not Found を返す
