## 機能概要

CollectionDetailPage で、各レコードを別のコレクションにコピーする機能を提供する。コピー先コレクションを選択するモーダルを表示し、同一コレクションへのコピーは選択肢から除外する。

## 意図

複数コレクション間でデータを共有・複製する操作を管理画面から直感的に行えるようにする。

## シナリオ

### レコードを別コレクションにコピーする

1. ユーザーがレコードカードの「コピー」ボタンをクリックする
2. コピー先コレクション選択モーダルが表示される（現在のコレクションは除外）
3. ユーザーがコピー先コレクションを選択して「コピー」をクリックする
4. `recordsApi.copy()` でバックエンドに送信する
5. 成功時はモーダルを閉じてレコード一覧をリロードする

## 受け入れ基準

- [ ] 各レコードに「コピー」ボタンが表示される
- [ ] モーダルでコピー先コレクションを選択できる
- [ ] 現在のコレクションは選択肢に表示されない
- [ ] コピー中はローディング状態が表示される
- [ ] エラー時はエラーメッセージが表示される
