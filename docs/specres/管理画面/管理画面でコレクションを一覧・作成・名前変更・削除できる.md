## 機能概要

React 管理画面の CollectionsPage で、コレクションのカード形式一覧表示、JSON Schema エディタ付きの新規作成フォーム、インライン名前変更、確認ダイアログ付き削除を提供する。

## 意図

LLM エージェント以外にも、人間の管理者がブラウザからコレクションを管理できるセカンダリ UI を提供する。

## シナリオ

### コレクションを一覧表示する

1. ユーザーが管理画面の `/` にアクセスする
2. `collectionsApi.list()` で全コレクションを取得する
3. カード形式で名前と ID を表示する

### コレクションを新規作成する

1. ユーザーが「新規作成」フォームを開く
2. コレクション名と JSON Schema を入力する
3. デフォルトスキーマテンプレートが事前入力されている
4. 送信後、`collectionsApi.create()` で作成する
5. 一覧が自動更新される

### コレクション名をインライン変更する

1. ユーザーが「名前変更」ボタンをクリックする
2. 名前がインライン編集可能になる
3. 新しい名前を入力して保存する

### コレクションを削除する

1. ユーザーが「削除」ボタンをクリックする
2. 確認ダイアログが表示される
3. 確認後、`collectionsApi.delete()` で削除する
