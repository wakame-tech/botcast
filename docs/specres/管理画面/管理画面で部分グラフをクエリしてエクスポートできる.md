## 機能概要

レコードカード内の「グラフ」ボタンから、そのレコードを起点として探索深度・エクスポート形式（json-canvas / markdown）を指定してサブグラフをクエリし、結果を表示・コピーできる。JSON Canvas 形式ではノード・エッジの構造データを表示し、Markdown 形式ではレンダリング済みテキストを表示する。

## 意図

レコード間の関係性を起点レコードから辿り、グラフ構造を視覚的に確認したりエクスポートデータとしてコピーできるようにする。LLM エージェントが使う Canvas API と同じ機能を人間が UI から操作できる。

## シナリオ

### JSON Canvas 形式で部分グラフをクエリする

1. ユーザーがレコードカードの「グラフ」ボタンをクリックする
2. 探索深度（デフォルト: 1）を設定する
3. エクスポート形式で「json-canvas」を選択する
4. `canvasApi.query()` でサブグラフを取得する
5. ノード数・エッジ数のサマリーと JSON データを表示する

### Markdown 形式で部分グラフをクエリする

1. ユーザーがグラフパネルで深度を設定する
2. エクスポート形式で「markdown」を選択する
3. `canvasApi.query()` でサブグラフを取得する
4. Markdown テキストをコードブロックで表示する

### クエリ結果をクリップボードにコピーする

1. ユーザーが部分グラフクエリを実行して結果が表示されている
2. 「コピー」ボタンをクリックする
3. JSON Canvas の場合は JSON 文字列、Markdown の場合はテキストがクリップボードにコピーされる

### 存在しないレコード ID でクエリする

1. 存在しないレコードのグラフボタンからクエリを実行する
2. API がエラーを返す
3. エラーメッセージが表示される
