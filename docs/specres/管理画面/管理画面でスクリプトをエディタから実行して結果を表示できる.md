- `web/src/pages/ScriptsPage.tsx`
- `web/src/api/client.ts`
- `web/src/types.ts`

## 機能概要

ScriptsPage で、Python3 または Node.js の言語選択、コードエディタ、プリロードコード入力、ネットワークアクセス切り替え、実行ボタン、実行結果（終了コード・stdout・stderr）の表示を提供する。

## 意図

LLM エージェントだけでなく、人間の管理者もブラウザからスクリプトを試行実行できるデバッグ・管理ツールを提供する。

## シナリオ

### Python3 スクリプトを実行する

1. ユーザーが言語に Python3 を選択する
2. コードエディタにコードを入力する
3. 「実行」ボタンをクリックする
4. `scriptsApi.execute()` でバックエンドに送信する
5. 終了コード・stdout・stderr が結果エリアに表示される

### ネットワークアクセス付きで実行する

1. ユーザーが「ネットワークアクセス」チェックボックスを有効にする
2. スクリプトを実行する
3. スクリプト内から外部 API 通信が可能になる
