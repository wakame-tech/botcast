## 機能概要

CollectionDetailPage で、複数のレコードを1つのターゲットレコードにマージする機能を提供する。マージモードを有効化し、複数のソースレコードとターゲットを選択、オプションでフィールド加算や元レコード削除を指定できる。

## 意図

関連するレコードを統合する操作を管理画面から直感的に行えるようにし、データ整理を効率化する。

## シナリオ

### 複数レコードを1つにマージする

1. ユーザーが「マージモード」ボタンをクリックしてマージモードを有効化する
2. マージするソースレコードを複数選択する（チェックボックス）
3. ターゲットレコードを1つ指定する
4. オプションで加算フィールド（カンマ区切り）と元レコード削除を設定する
5. 「マージ実行」ボタンをクリックする
6. `recordsApi.merge()` でバックエンドに送信する
7. 成功時はマージモードを解除してレコード一覧をリロードする

## 受け入れ基準

- [ ] 「マージモード」ボタンでモードを切り替えられる
- [ ] マージモード中は各レコードにチェックボックスが表示される
- [ ] 選択したレコードからターゲットを1つ指定できる
- [ ] 加算フィールドをカンマ区切りで入力できる
- [ ] 元レコード削除オプションを設定できる
- [ ] 2つ以上のレコードとターゲットが選択されないとマージ実行できない
- [ ] マージ中はローディング状態が表示される
- [ ] エラー時はエラーメッセージが表示される
