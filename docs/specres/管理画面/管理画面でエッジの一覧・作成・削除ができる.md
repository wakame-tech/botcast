## 機能概要

レコード詳細画面の各レコードカード内に、エッジ（グラフリレーション）の一覧表示・新規作成・削除機能を統合する。「エッジ」ボタンをクリックすると、そのレコードのエッジ一覧が展開され、インラインでエッジ作成・削除ができる。

## 意図

Canvas API のエッジ管理機能をブラウザから操作できるようにし、管理者がレコード間の関係性を視覚的に確認・編集できるセカンダリ UI を提供する。

## シナリオ

### レコードのエッジを一覧表示する

1. ユーザーがレコードカードの「エッジ」ボタンをクリックする
2. `canvasApi.listEdges(recordId)` で関連エッジを取得する
3. from / to / label / 作成日時をテーブル形式でカード内に表示する

### エッジを新規作成する

1. ユーザーがエッジパネルの「+ エッジ作成」をクリックする
2. to（送信先レコード ID）と label を入力する（from は現在のレコード）
3. 送信後、`canvasApi.createEdge()` で作成する
4. エッジ一覧が自動更新される

### エッジを削除する

1. ユーザーがエッジ行の「削除」ボタンをクリックする
2. 確認ダイアログが表示される
3. 確認後、`canvasApi.deleteEdge()` で削除する
4. エッジ一覧が自動更新される

### 存在しないレコード ID でエッジ作成を試みる

1. ユーザーが存在しないレコード ID を入力してエッジ作成する
2. API が 404 エラーを返す
3. エラーメッセージが表示される
