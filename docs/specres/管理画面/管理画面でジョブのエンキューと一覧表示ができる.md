## 機能概要

JobsPage で、ジョブ名と JSON パラメータを指定してジョブをエンキューするフォームと、ジョブ一覧をステータスバッジ（色分け：completed=緑, error=赤, waiting/in_progress=灰）付きで表示する機能を提供する。

## 意図

バックグラウンドジョブの投入と監視を管理画面から行えるようにする。

## シナリオ

### ジョブをエンキューする

1. ユーザーが「ジョブ作成」フォームを開く
2. ジョブ名と JSON パラメータを入力する
3. 送信後、`jobsApi.create()` でエンキューする

### ジョブ一覧を表示する

1. ユーザーが `/jobs` にアクセスする
2. `jobsApi.list()` で全ジョブを取得する
3. 各ジョブの名前・パラメータ・ステータスバッジを表示する
