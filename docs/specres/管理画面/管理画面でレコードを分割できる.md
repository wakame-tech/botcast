## 機能概要

CollectionDetailPage で、1つのレコードを複数の新規レコードに分割する機能を提供する。分割データをJSON配列で入力し、元レコードのデータを基に新規レコードを生成する。

## 意図

1つのレコードに集約されたデータを複数のレコードに分離する操作を管理画面から直感的に行えるようにする。

## シナリオ

### レコードを複数に分割する

1. ユーザーがレコードカードの「分割」ボタンをクリックする
2. 分割設定モーダルが表示される
3. ユーザーが分割データをJSON配列形式で入力する（例: `[{}, {"name": "new1"}, {"name": "new2"}]`）
4. 「分割実行」ボタンをクリックする
5. `recordsApi.split()` でバックエンドに送信する
6. 成功時はモーダルを閉じてレコード一覧をリロードする

## 受け入れ基準

- [ ] 各レコードに「分割」ボタンが表示される
- [ ] モーダルで分割データをJSON配列形式で入力できる
- [ ] 無効なJSONの場合はエラーメッセージが表示される
- [ ] 空配列の場合はエラーメッセージが表示される
- [ ] 分割中はローディング状態が表示される
- [ ] エラー時はエラーメッセージが表示される
