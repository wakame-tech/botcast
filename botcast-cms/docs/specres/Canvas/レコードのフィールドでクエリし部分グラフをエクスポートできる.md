## 機能概要

レコードのフィールド条件やグラフ走査の深さを指定してクエリを実行し、マッチしたレコードとそのエッジで構成される部分グラフを JSON Canvas 形式または Markdown 形式でエクスポートできる。クエリ処理はすべて SurrealQL のグラフ走査構文（`->edge->?`）と `WHERE` 句で DB 上で実行される。

## 意図

グラフとして蓄積された情報を、LLM エージェントが特定の視点（例：ある登場人物に関連する情報のみ、ある時点までのエピソードのみ）で切り出してファイルとして取得できるようにする。これにより、コンテキストウィンドウに収まる形で構造化された情報を LLM に渡せる。

## 主要なメンバー

- `CanvasQueryRequest` — クエリリクエスト（`record_id`, `conditions`, `depth`, `format`）
- `CollectionRepository::query_subgraph()` — SurrealQL グラフ走査で部分グラフ取得
- `build_surql_where()` — JSON 条件オブジェクトを SurrealQL `WHERE` 句に変換
- `build_json_canvas()` — 部分グラフを JSON Canvas 仕様に変換
- `build_markdown()` — 部分グラフを Markdown テキストに変換

## 実装詳細

### SurrealQL クエリ戦略

1. **グラフ走査**: `->edge->?` を `depth` 回繰り返してパスを構築し、`array::distinct(array::flatten(...))` で到達可能レコード ID を一括取得
   - 例: depth=2 → `SELECT VALUE ->edge->?->edge->? FROM ONLY {record_id}`
2. **レコード取得**: `SELECT * FROM [id1, id2, ...] WHERE {conditions}` で条件フィルタ付き一括取得
3. **エッジ取得**: `SELECT * FROM edge WHERE in INSIDE [...] AND out INSIDE [...]` で関連エッジを一括取得

### 条件フィルタ

JSON 条件オブジェクトを SurrealQL の `WHERE` 句に変換する。対応演算子:

| JSON 演算子 | SurrealQL |
| ----------- | --------- |
| `$eq`       | `=`       |
| `$ne`       | `!=`      |
| `$lt`       | `<`       |
| `$lte`      | `<=`      |
| `$gt`       | `>`       |
| `$gte`      | `>=`      |

例: `{"data.episode_number": {"$lte": 5}}` → `WHERE data.episode_number <= 5`

## シナリオ

### JSON Canvas 形式で部分グラフをエクスポートする

1. クライアントが `POST /canvas/query` に `{ "record_id": "{table}:{id}", "depth": 2, "format": "json-canvas" }` を送信する
2. API が SurrealQL で `SELECT VALUE ->edge->?->edge->? FROM ONLY {record_id}` を実行し到達可能 ID を取得する
3. `SELECT * FROM [ids...]` で全レコードを一括取得する
4. `SELECT * FROM edge WHERE in INSIDE [ids...] AND out INSIDE [ids...]` で関連エッジを一括取得する
5. レコード群とエッジ群を JSON Canvas 仕様（nodes + edges）に変換する
6. 200 OK で JSON Canvas オブジェクトを返す

### Markdown 形式で部分グラフをエクスポートする

1. クライアントが `POST /canvas/query` に `{ "record_id": "{table}:{id}", "depth": 1, "format": "markdown" }` を送信する
2. API が SurrealQL でグラフ走査 + レコード/エッジ一括取得を行う
3. 各レコードをセクション、エッジをリレーション表として Markdown テキストに変換する
4. 200 OK で Markdown 文字列を返す

### フィールド条件で絞り込んだ部分グラフを取得する

1. クライアントが `POST /canvas/query` に `{ "record_id": "{table}:{id}", "depth": 3, "conditions": {"data.episode_number": {"$lte": 5}}, "format": "json-canvas" }` を送信する
2. API が条件を SurrealQL の `WHERE data.episode_number <= 5` に変換し、レコード取得クエリに適用する
3. 条件にマッチしたレコードとそのエッジのみを返す

### 起点レコードが存在しない場合

1. クライアントが存在しない `record_id` でクエリを実行する
2. API が 404 Not Found を返す
