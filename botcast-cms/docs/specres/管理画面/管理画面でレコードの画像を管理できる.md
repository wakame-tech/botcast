## 機能概要

CollectionDetailPage で、各レコードに画像をアップロード・プレビュー・削除する機能を提供する。フィールド名を指定して画像をアップロードし、レコードのimages配列に追加する。

## 意図

レコードに関連する画像データを管理画面から直接管理できるようにする。

## シナリオ

### レコードに画像をアップロードする

1. ユーザーがレコードカードの「画像追加」ボタンをクリックする
2. 画像アップロードモーダルが表示される
3. ユーザーがフィールド名を入力し、画像ファイルを選択する
4. プレビューが表示される
5. 「アップロード」ボタンをクリックする
6. `imagesApi.upload()` でバックエンドに送信（base64エンコード）する
7. 成功時はモーダルを閉じてレコード一覧をリロードする

### レコードの画像を削除する

1. ユーザーがレコードカードの画像横の「削除」ボタンをクリックする
2. 確認ダイアログが表示される
3. ユーザーが確認すると `imagesApi.delete()` でバックエンドに送信する
4. 成功時はレコード一覧をリロードする

## 受け入れ基準

- [ ] 各レコードに「画像追加」ボタンが表示される
- [ ] モーダルでフィールド名を入力できる
- [ ] 画像ファイルを選択できる
- [ ] 選択した画像のプレビューが表示される
- [ ] アップロード中はローディング状態が表示される
- [ ] レコードの既存画像一覧が表示される
- [ ] 各画像に削除ボタンが表示される
- [ ] 削除前に確認ダイアログが表示される
- [ ] エラー時はエラーメッセージが表示される
