## 機能概要

コレクションに対する CRUD 操作（一覧取得 `GET /collections`, 詳細取得 `GET /collections/{id}`, 名前変更 `PUT /collections/{id}`, 削除 `DELETE /collections/{id}`）を REST API で提供する。削除時は関連するレコードも全て削除される。

## 意図

LLM エージェントや管理画面からコレクションのライフサイクルを完全に管理できるようにするため。

## 主要なメンバー

- `UpdateCollection { name }` — 名前変更リクエストボディ
- `CollectionRepository` トレイト — 永続化操作の抽象化

## シナリオ

### コレクション一覧を取得する

1. クライアントが `GET /collections` を送信する
2. SurrealDB から全コレクションを取得する
3. 200 OK でコレクション配列を返す

### コレクションの詳細を取得する

1. クライアントが `GET /collections/{id}` を送信する
2. SurrealDB から該当コレクションを取得する
3. 200 OK でコレクション情報を返す

### コレクション名を変更する

1. クライアントが `PUT /collections/{id}` に新しい `name` を送信する
2. SurrealDB で `merge` 操作により名前を更新する
3. 200 OK で更新後のコレクションを返す

### コレクションを削除する

1. クライアントが `DELETE /collections/{id}` を送信する
2. コレクションメタデータを削除する
3. 関連する全レコードも削除する
4. 204 No Content を返す
