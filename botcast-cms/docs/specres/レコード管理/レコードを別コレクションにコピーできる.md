## 機能概要

レコードを別のコレクションにコピーする API (`POST /records/{collectionId}/{recordId}/copy`) を提供する。コピー先コレクションのスキーマに対してバリデーションを行い、適合する場合のみコピーが成功する。

## 意図

LLM エージェントがデータを別のコレクションに複製して再利用できるようにする。例えば、テンプレートコレクションから本番コレクションへのデータ移行や、バックアップ目的でのコピーを可能にする。

## 主要なメンバー

- `CopyRecordRequest` — コピー先コレクション ID を含むリクエスト
- `CollectionRepository::copy_record()` — レコードコピーの実行

## シナリオ

### 正常系: レコードを別コレクションにコピーする

1. クライアントが `POST /records/{collectionId}/{recordId}/copy` に `{ "target_collection_id": "..." }` を送信する
2. API がコピー元レコードを取得する
3. API がコピー先コレクションのスキーマを取得する
4. `validate_record()` でコピー元データをコピー先スキーマで検証する
5. バリデーション成功後、コピー先コレクションに新規レコードを作成する
6. 201 Created で新規レコードを返す

### 異常系: コピー先スキーマに適合しない

1. クライアントが `POST /records/{collectionId}/{recordId}/copy` を送信する
2. API がコピー元データをコピー先スキーマで検証する
3. バリデーションエラーが発生する
4. 400 Bad Request で `VALIDATION_ERROR` を返す

### 異常系: コピー元レコードが存在しない

1. クライアントが存在しないレコード ID でコピーを要求する
2. 404 Not Found で `NOT_FOUND` を返す

### 異常系: コピー先コレクションが存在しない

1. クライアントが存在しないコレクション ID をコピー先に指定する
2. 404 Not Found で `NOT_FOUND` を返す
