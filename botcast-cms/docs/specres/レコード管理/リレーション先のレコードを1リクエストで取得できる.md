## 機能概要

レコード一覧取得時にリレーション（エッジ）先のレコードを展開して1リクエストで返す API エンドポイント `GET /records/{collectionId}/with-relations` を提供する。従来はレコード取得 → エッジ一覧取得 → 各関連レコード取得と N+1 リクエストが必要だったが、サーバー側で一括取得することで1リクエストに集約する。

## 意図

管理画面やLLMエージェントがレコードとそのリレーション情報を効率的に取得できるようにする。N+1 クエリ問題を解消し、UI のレスポンスを改善する。

## 主要なメンバー

- `RecordWithRelations` — レコード本体 + リレーション情報を含むレスポンス型
- `RelatedRecord` — エッジ情報と関連先レコードのペア
- `CollectionRepository::list_records_with_relations()` — 全レコードのエッジ・関連先を一括取得
- `records_with_relations_handler()` — カスタム Axum ハンドラ

## シナリオ

### レコード一覧をリレーション付きで取得する

1. クライアントが `GET /records/{collectionId}/with-relations` を送信する
2. API がコレクション内の全レコードを取得する
3. 各レコードについてエッジ一覧を取得し、エッジの先にあるレコードを取得する
4. レコード本体にリレーション情報を付与して 200 OK で返す

### リレーションが存在しないレコードを含む場合

1. エッジの無いレコードは `relations: []` として返される
2. エッジはあるがリレーション先レコードが既に削除されている場合、そのリレーションはスキップされる

### 管理画面でリレーション付きレコード一覧を表示する

1. 管理画面の CollectionDetailPage がリレーション付き API を呼び出す
2. 各レコードカードの下にリレーション先のレコード情報がインライン表示される
3. N+1 リクエストが不要になり、表示が高速化される
