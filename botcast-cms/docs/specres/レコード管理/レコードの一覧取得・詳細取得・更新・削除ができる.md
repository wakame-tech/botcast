## 機能概要

レコードに対する読み取り・更新・削除操作（`GET /records/{collectionId}`, `GET /records/{collectionId}/{recordId}`, `PUT /records/{collectionId}/{recordId}`, `DELETE /records/{collectionId}/{recordId}`）を REST API で提供する。更新時もスキーマバリデーションが適用される。

## 意図

レコードの完全なライフサイクル管理を提供し、LLM エージェントが構造化データを自由に操作できるようにする。

## 主要なメンバー

- `CollectionRepository::list_record()` — コレクション内全レコードの取得
- `CollectionRepository::get_record()` — 単一レコードの取得
- `CollectionRepository::update_record()` — スキーマ検証付き更新
- `CollectionRepository::delete_record()` — レコード削除

## シナリオ

### コレクション内のレコード一覧を取得する

1. クライアントが `GET /records/{collectionId}` を送信する
2. SurrealDB から該当コレクションの全レコードを取得する
3. 200 OK でレコード配列を返す

### レコードを更新する

1. クライアントが `PUT /records/{collectionId}/{recordId}` にデータを送信する
2. API がコレクションのスキーマを取得する
3. `validate_record()` で新しいデータを検証する
4. バリデーション成功後、SurrealDB のレコードを更新する
5. 200 OK で更新後のレコードを返す

### レコードを削除する

1. クライアントが `DELETE /records/{collectionId}/{recordId}` を送信する
2. SurrealDB から該当レコードを削除する
3. 204 No Content を返す
