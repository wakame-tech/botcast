## 機能概要

アプリケーション起動時に `.env` から環境変数を読み込み、SurrealDB リポジトリ・DifySandboxClient・BotcastWorker を初期化して `AppState` に集約する。Axum サーバーに CORS ミドルウェアを設定し、OpenAPI 仕様から生成されたルーティングで HTTP リクエストを受け付ける。

## 意図

リポジトリパターンと依存注入により、ビジネスロジックとデータアクセスを分離し、テスタビリティと保守性を確保する。

## 主要なメンバー

- `AppState { dify_sandbox_client, worker, collection_repo }` — アプリケーション状態
- `ApiImpl` — OpenAPI トレイト実装体。AppState を保持し各ハンドラを実装
- `SurrealCollectionRepository` — `CollectionRepository` トレイトの SurrealDB 実装
- `CorsLayer::permissive()` — 全オリジン許可の CORS 設定

## シナリオ

### アプリケーションが正常に起動する

1. `.env` ファイルから環境変数を読み込む
2. BotcastWorker を初期化してバックグラウンドで起動する
3. SurrealCollectionRepository を環境変数から作成する
4. DifySandboxClient を環境変数から作成する
5. AppState に全依存を集約する
6. Axum サーバーを `SERVER_HOST:SERVER_PORT` でバインドする
7. CORS を permissive に設定して HTTP リクエストを受け付ける
